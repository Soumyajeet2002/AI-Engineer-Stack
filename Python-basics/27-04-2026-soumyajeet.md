# Variable Names
- a variable ca have a short name , or a more descriptive name
 
## Simple rules for Python 
- A variable name must start with a letter or the underscore character
- A variable name cannot start with a number
- A variable name can only contain alpha-numeric characters and underscores (A-z, 0-9, and _ )
- Variable names are case-sensitive (age, Age and AGE are three different    variables)
- A variable name cannot be any of the Python keywords.

```
my_var = "john"
myVar = "john"
_my_var = "John"
myVar = "John"
MYVAR = "John"
myvar2 = "John"

-> all of this is valid Variable names.
```

## Multi Word Variable Names.
- Variable names with more than one word can be diffcult to read. 
- there are several techniques we can make them readable.

### Camel Case
- in this each word , except the first word , starts with a Capital letter.
```
myVariableName = " John "
myName = " Soumyajeet Nayak "

-> in this each word except the first starts with a captical Letter.
```

### Pascal Case
- in this each word , starts with a Captical letter.

```
MyVariableName = "Nayak"
MyName = " Soumayjeet Nayak "
```

### Snake Case
- in this each word is seperated by a underscore " _ ".

```
my_name = "Jeet"
my_variable_name = " Soumyajeet Nayak "

-> this is an example of Snake Case.
```
