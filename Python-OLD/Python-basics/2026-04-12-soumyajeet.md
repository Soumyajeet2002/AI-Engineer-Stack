# Variables and Data Types

## Creating Variables

- Python has no commands to <b>DECLARE</b> a variable
- A variable is created the moment you first assign a value to it.

- <i>EXAMPLE<i>
 ```
 x = 5 
 y = 'JEET'
 print(x)
 print(y)
 ```
- Variables do need to be declared with any particular type and can even change type after they have been set.

- <i>EXAMPLE</i>
```
x = 4          # x is of type int
x = 'jeet'    # x is of type str
print(x)
```
## Casting
- If you want to specify the data type of a variable , this can be done with casting 

- <i>EXAMPLE</i>
```
x = str(3)
y = int(3)
z = float(3)

```
