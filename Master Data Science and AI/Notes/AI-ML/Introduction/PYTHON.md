# Variable and Keywords
## Variables 
- Are temporary storage / space where we can keep changing values.
- Assigning Values to Variables in python we use **" = "** operator.
- `a = 10` `a = WELCOME`
- No need to Define Type / Data Type for variables.
### Keywords
- Special reserved words which convey a special meaning to interpreter or compiler.
- It can't be used a  variables.
- Few Examples:
	- def , if , else , continue , class , break , finally , lambda, except , import  , None......
	- These are predefined in the Python language with some special meanings. Or predefined Meaning.
# Data Types
## What is a data type
- Simply mean what type of data we have.
## Data types are divided into 5 different types
### Numeric
- Holds Number
- they are of 3 different types
	- Integer
	- float
	- complex numbers
### Dictionary
- which holds data in KEY and Value pair
- EX -> We have customer Id (KEY) and customer Name(KEY)
- id = 0001 (value) , name = "Soumyajeet" (value)
### Boolean
- True and False value
### Set
### Sequence Type
- they store values / records in sequence
- They are of 3 types
	- STRING
		- like HELLOWORLD -> HELLO has 5 Characters it can new be indexed 
	- TUPLES
	- LISTS
- Variables holds values of different data types.
- with the help of type() function we can check the data types.
