# Variable and Keywords
## Variables 
- Are temporary storage / space where we can keep changing values.
- Assigning Values to Variables in python we use **" = "** operator.
- `a = 10` `a = WELCOME`
- No need to Define Type / Data Type for variables.
### Keywords
- Special reserved words which convey a special meaning to interpreter or compiler.
- It can't be used a  variables.
- Few Examples:
	- def , if , else , continue , class , break , finally , lambda, except , import  , None......
	- These are predefined in the Python language with some special meanings. Or predefined Meaning.
